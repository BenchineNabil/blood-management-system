
# Database

## Purpose
This folder contains the database structure and database-related files.

## Technology
- MySQL

## Responsibilities
- Define database tables and relationships.
- Maintain database schema and migrations.
- Provide initial seed data when needed.
- Ensure data consistency through constraints and relationships.

## Important Rules
- Follow the agreed database design.
- Do not create duplicate tables for the same concept.
- Use foreign keys where appropriate.
- Store passwords securely as hashes, never as plain text.
- Protect confidential donor and patient information.
- Coordinate schema changes with the backend developers.
