
# Technology Stack

## 1. Frontend
- React.js
- JavaScript
- CSS
- Axios for API communication

## 2. Backend
- Node.js
- Express.js
- JavaScript
- REST API

## 3. Database
- MySQL
- mysql2 for Node.js database connectivity

## 4. Development Tools
- Git
- GitHub
- Visual Studio Code
- Postman for API testing

## 5. Architecture
The application follows a three-layer architecture:

- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MySQL

The frontend communicates with the backend through REST APIs.
The backend communicates with MySQL to store and retrieve data.
