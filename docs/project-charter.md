
# Blood Management System

## 1. Project Overview
A software system designed to manage blood donations, blood inventory, and blood requests.

## 2. Problem Statement
Managing blood donations and blood availability can be difficult without an organized system. This project aims to provide a centralized platform to facilitate blood management.

## 3. Project Objectives
- Manage blood donors.
- Track blood inventory.
- Manage blood requests.
- Improve communication between donors and blood banks.

## 4. Stakeholders
- Blood donors
- Blood banks
- Hospitals
- System administrators

## 5. Project Methodology
The team will use Agile Scrum with short development sprints.
