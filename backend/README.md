

# Backend

## Purpose
This folder contains the server-side logic of the Blood Bank Management System.

## Technology
- Node.js
- Express.js
- JavaScript
- MySQL2

## Main Modules
- Authentication
- Dashboard
- Inventory
- Requests
- Donors
- Questionnaire
- Donations
- Reminders
- User Management

## Responsibilities
- Implement business logic.
- Provide REST APIs for the frontend.
- Validate incoming data.
- Handle authentication and authorization.
- Communicate with the database.
- Calculate stock statistics and expiration information.

## Important Rules
- The frontend must not access the database directly.
- Keep business logic on the backend.
- Validate data before database operations.
- Follow the agreed database design and API contracts.
