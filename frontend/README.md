
# Frontend

## Purpose
This folder contains the user interface of the Blood Bank Management System.

## Technology
- React.js
- JavaScript
- CSS
- Axios for API communication

## Main Features
- Authentication
- Dashboard
- Blood Stock
- Blood Requests
- Donor Management
- Donor Eligibility Questionnaire
- Donation Registration
- Reminders
- User Management

## Responsibilities
- Build screens and reusable components.
- Handle user interactions and form validation.
- Communicate with the backend through REST APIs.
- Display data received from the backend.

## Important Rules
- Do not connect directly to the database.
- Do not implement business rules that belong to the backend.
- Follow the agreed API contracts.
- Reuse shared components whenever possible.
